关于本馆命名 · 方法 · 边界 · 局限

为什么叫「积玉堆琼」

「丽江雪山天下绝，积玉堆琼几千叠。」

—— 元 · 李京《雪山歌》

李京，元代云南宣慰副使，其《雪山歌》是已知最早题咏玉龙雪山的诗篇——「积玉堆琼」四字写的就是这座城背后的那座山：积雪如玉、堆琼似叠，十三峰直上摩天。展馆立于山麓坝子之上，五族的文化也如山般层层堆叠，故名。另有一个本地古雅称——「玉壁金川」（玉璧指玉龙雪山、金川指金沙江，相传为清雍正三年丽江郡丞聂瑞题刻，出处见《中国纳西族》一书，实物待核实）——因与丽江本地酒店重名而未采用。

本馆是什么
一个策展层
丽江五族文化的优质数字资源散落在国会图书馆、国家图书馆、识典古籍、非遗网、语保平台等数十个平台。本馆做整理、转译与可视化——为公众修一条抵达权威资源的路，而非替代它们。
一个缺口陈述
丽江市博物院（东巴文化博物馆，国家二级馆）至今没有线上展厅；傈僳、普米的开放影像几近空白。把这两个空白如实展出，是本馆存在的一个理由。
一次落地实验
本站验证「资源聚合型线上文化展馆」的可行性——对应《关于推进实施国家文化数字化战略的意见》「统筹利用已建或在建数字化工程和数据库成果」的方向。它欢迎被更大的机构版本取代，那将是它最好的结局。
不是「博物馆」
依《博物馆条例》，「博物馆」名称需备案登记。本站为非官方公益策展，不自称博物馆，不进行文物认定与收藏。
方法论：三层内容策略
第一层 · 直接呈现
仅使用开放授权材料：Wikimedia Commons 的 CC0 / 公有领域 / CC BY / CC BY-SA 图片（逐图署名、本地化保存）与纯事实性数据（人口普查、非遗名录批次、遗产年份）。所有事实带来源。
第二层 · 外链导流
有明确权利方的资源（纪录片、机构数据库、语保平台）只做目录级揭示与跳转，不搬运、不剪辑、不嵌播——版权边界即产品边界。
第三层 · 原创策展
词条撰写、叙事线、可视化与「非遗申报地边界」标注为本馆原创，欢迎注明出处的非商业转载。
事实核查原则：全部约 140 次网络检索、每条关键事实附来源；两说并存的注明（如元设丽江路 1274/1276）；无法核实的宁可不写。调研中主动核正了两处常见误传（东巴纸申报地、火把节申报地）与一处人物生卒（方国瑜 1903—1983）。
表述伦理：涉宗教内容（东巴教、毕摩、达巴、韩规）一律学术性描述；摩梭「走婚」采用「阿夏异居婚」的学术表述，拒绝猎奇化；遵循《云南省纳西族东巴文化保护条例》第 19 条「不得歪曲、贬损」之规定，本站内容上线前经过事实复核。

诚实的局限清单
未核实 · 人口类
宁蒗彝族精确人口数（县级公报未单列）；云南境内摩梭人口精确数；华坪县分民族数据。
未核实 · 名录类
「普米族四弦舞乐」非遗级别（兰坪口径已注，宁蒗本地待查）；「黎明傈僳族传统文化保护区」是否列入省级名录。
未核实 · 文献类
柏林民族学博物馆与法国国家图书馆的东巴经收藏数量；「玉壁金川」题刻的实物位置；在世资深老东巴名单（动态信息，建议向丽江市东巴文化研究院函询）。
刻意留白
普米馆与傈僳馆的人像影像缺口——开放影像库中几近空白，本馆不用他族图片凑数。
未收录 · 字谱类
东巴字谱页未标注单字纳西读音（需《纳西象形文字谱》等工具书，无开放电子版）；Commons 另有 29 个 TRON 编码东巴 GIF 字形，因无对应释义而未收录。
空缺 · 声音档案
五族民族语的真实录音在开放平台为零（2026-10 经 Commons / Lingua Libre API 系统检索）；Internet Archive 民族音乐档案因网络不可达未及核验。语音导览以普通话合成朗读如实代偿，不以机器合成冒充民族语。

把「不知道」写出来，和把「知道」写出来一样重要。以上条目欢迎任何了解者提供线索——本馆会更新并致谢。

技术说明与共建邀请
零构建纯静态站
纯 HTML / CSS / 原生 JS，无任何构建链与运行时依赖；图片全部本地化。整个站点可拖拽部署到 Cloudflare Pages / GitHub Pages，或拷入 U 盘离线打开。
三个互动展项（v1.3）
东巴文字谱：13 个单字字形来自 Commons「Dongba symbols」系列（CC0 / CC BY-SA 逐图署名），借音三例出自英文维基百科词条；全量 1,400+ 字表因工具书无开放授权，未予截图书录。语音导览：浏览器原生 Web Speech 普通话朗读；开放平台（Commons / Lingua Libre）经 API 系统检索确认无五族民族语真实录音——真实音声列为机构合作方向。三维展厅：Three.js（CDN）+ 本站开放授权影像 16 幅；WebGL / CDN 不可用时自动降级为平面画廊。
字体策略
中文使用系统字体栈（Noto Serif SC / 思源宋体 / 宋体），彝文依赖系统彝文字体（Microsoft Yi Bai），傈僳文通过 CDN 引入 OFL 开源字体 Noto Sans Lisu（离线时优雅降级）。东巴文曾评估内嵌 BabelStone Naxi 字体（2,162 字形）——因该字体未附再分发许可，本站不内嵌，官方链接见资源目录。
