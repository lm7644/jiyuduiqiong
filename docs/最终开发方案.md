## 一、项目定位

**名称**：金生丽水 · 丽江五族文化线上展馆
**英文名**：Jin Sheng Li Shui — Gold Born of the River · Lijiang's Living Cultures
**命名出处**：《千字文》"金生丽水，玉出昆冈"。丽江因金沙江古称"丽水"得名（《元史·地理志》："路因江为名"）。名称避开"博物馆"字样（规避《博物馆条例》备案资质问题）。
**一句话定位**：国内首个地市级多民族"资源聚合型"线上文化展馆——丽江五族文化的策展层与入口层（数据在权威机构，叙事在这里）。

**叙事主线**：一城五族（纳西、彝、傈僳、白、普米）+ 摩梭人专题，以"各民族交往交流交融"为价值底色。

## 三、内容策略与版权合规（三层模型）

1. **直接呈现层**：Wikimedia Commons 开放授权图片（56 张已下载本地化，逐图署名 CC BY/BY-SA/CC0/PD）；纯事实性数据（人口普查、非遗名录批次）
2. **外链导流层**：权威机构资源（国图特藏库、识典古籍、语保平台、UNESCO、非遗网）只做目录级揭示 + 跳转
3. **原创策展层**：词条撰写、可视化、叙事线为原创，采用"注明出处"的学术引用格式
- 全站图片逐张标注：作者 / 许可证 / Commons 来源页
- 民俗表述遵循"非遗申报地边界"原则：民族共有文化（如火把节）与属地申报项目（如宁蒗拈达则）明确区分
- 涉宗教内容（东巴教、毕摩、达巴、韩规）一律学术性描述，无信仰引导文案

## 四、技术决策（零构建纯静态站）

**决策依据**：目标环境无 node/npm（已实测），网络可下载开放资源（已实测 GitHub API 200 / Wikimedia 可达）。零构建 = 任何静态托管直接部署、file:// 直接打开、无供应链风险。

| 层 | 选型 | 说明 |
|---|---|---|
| 页面 | 纯 HTML5 多页 | SEO 友好、无 JS 也可读 |
| 样式 | 单文件 main.css 设计系统（CSS 自定义属性） | 主题色按民族切换 |
| 脚本 | 原生 JS（app.js，~300 行） | IntersectionObserver 滚动渐显、灯箱、时间线筛选、计数器、移动导航 |
| 字体 | 系统字体栈（Noto Serif SC / 思源宋体 / 宋体 fallback） | 不依赖外网字体，保证离线可用 |
| 图片 | 56 张 Commons 开放授权图，本地化 | 1920px 档，逐图署名 |
| 地图 | 自绘 SVG 示意世界地图 + 五族分布采用 Commons 现成分布图 | 规避审图号问题 |
| 交互 | 锚点导航、灯箱画廊、非遗手风琴、时间线时代筛选 | 全部渐进增强 |

**与调研报告方案的对应关系**：报告建议的 Astro/GSAP/Pannellum 等为"标准路线"，本次因环境约束改为等效零构建实现；云部署路径不变（Cloudflare Pages 拖拽即部署）。后续如引入 3D 展厅，按调研报告接入 openvgal 生成产物（iframe 嵌入）即可，与当前架构兼容。

## 六、已核实的核心事实底座（写进页面的依据）

- 七普丽江：彝 240,716 / 纳西 231,154 / 傈僳 111,247 / 白 58,568 / 普 19,380；少数民族占 56.44%
- 三项世界遗产：丽江古城 1997.12（C(II)(IV)，大研+白沙+束河 512 公顷）、三江并流 2003.7.2（170 万公顷，丽江境内老君山片区）、东巴古籍 2003.8（世界记忆遗产）
- 8 项国家级非遗（批次已逐项核实）；两处更正：东巴纸申报地为香格里拉、火把节申报地为楚雄/凉山
- 关键年份：1253 革囊渡江 / 1274-1276 丽江路 / 1382 赐姓木 / 1639 徐霞客（"宫室之丽，拟于王者"）/ 1723 改土归流 / 1903 方国瑜生 / 1922 洛克到丽江 / 1986.12.8 国家历史文化名城 / 1996.2.3 大地震（7.0 级，309 人遇难）/ 2005 东巴条例
- 纳西语 UNESCO 图谱（2010 版）："脆弱（vulnerable）"级——最轻一级；支系语言（拉热、玛丽玛萨）濒危更重
- 玉龙雪山主峰扇子陡 5596 米，纳西语"欧鲁"（波石欧鲁，"白沙的银色山岩"）
- 全部事实附来源 URL，见各页脚注与 about 页方法论

## 八、部署说明

1. **Cloudflare Pages**（推荐，免备案）：登录 dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → 直接拖入 `jinsheng-lishui` 文件夹（不含 docs 与 _tools）→ 完成后绑定自定义域名。零构建配置。
2. **GitHub Pages**：把 `jinsheng-lishui/` 推到仓库，Settings → Pages → 选 main 分支根目录。
3. **国内正式传播**：需购国内云主机/对象存储 + ICP 备案 + 公安备案后再切换；本站内容不涉经营性服务，备案为非经营性性质即可。
4. 图片均已本地化，部署后无外链依赖（打开即完整可用）。
