## 一、部署（三选一）

### Cloudflare Pages（推荐，免费、免备案、自带 CDN 与 HTTPS）
1. 登录 dash.cloudflare.com → 左侧栏 **Compute (Workers)**（旧版叫 Workers & Pages）→ Workers & Pages → Create application → 顶部标签切到 **Pages**（默认在 Workers 上，注意切换）
2. 找不到入口时用直达 URL：`https://dash.cloudflare.com/<account-id>/pages/create`（account id 是登录后地址栏里那串 32 位字符）
3. **方式 A（连接私有仓库，推荐）**：选 **Connect to Git** → 授权 GitHub → 选 `lm7644/jiyuduiqiong` → 构建命令留空、输出目录留空（纯静态根目录）→ Save and Deploy。此后每次在 GitHub 改动自动重新部署
4. **方式 B（无仓库拖拽）**：选 **Upload assets**，把 `jiyuduiqiong/` 整个文件夹拖入 → Deploy
5. 得到 `xxx.pages.dev` 域名即已上线；`_headers` 会被自动应用（安全头 + 缓存策略已配置）

### GitHub Pages
1. 前提：仓库为**公开**（或你有 GitHub Pro）。Settings → Pages → Deploy from a branch → main
2. 部署在 `https://lm7644.github.io/jiyuduiqiong/` 子路径——本站全部链接为相对路径，天然兼容；`404.html` 自动生效
3. 注意：GitHub Pages **不支持 `_headers`**，安全头可忽略（纯静态站风险低）

### 传统虚拟主机 / 对象存储
- 整个文件夹上传即可；确保 MIME：`.html` text/html、`.svg` image/svg+xml、`.webp/.jpg` image/*

## 二、绑定自有域名后必须改的两处

| 文件 | 改什么 |
|---|---|
| `sitemap.xml` | 15 个 `<loc>/xxx.html</loc>` 改为 `<loc>https://你的域名/xxx.html</loc>`（sitemap 规范要求绝对 URL，相对路径无效） |
| 各页 `<meta property="og:image" …>` | `assets/img/…` 改为 `https://你的域名/assets/img/…`（社交分享卡片需要绝对地址；16 页页头各一处，全局替换 `content="assets/img/` → `content="https://你的域名/assets/img/` 即可） |

改完重新部署一次。
