# 上线清单 · 积玉堆琼

站点为纯静态零构建，任何静态托管开箱即用。以下按顺序执行即可。

## 〇、GitHub 开源路线（推荐：开源 + 部署一次打通）

本仓库无 git 环境时，用 [GitHub Desktop](https://desktop.github.com/) 图形化完成（步骤见 README「最短开源 + 上线路径」）；命令行等价操作也在 README。

- **仓库结构**：只需推送 `jinsheng-lishui/` 文件夹内容（LICENSE / .gitignore / README 已备好；外层 `_tools/` 是本地工作脚本，不必入仓库——`.gitignore` 已排除）
- **GitHub Pages 注意**：
  - 部署在 `https://<user>.github.io/<repo>/` **子路径**下——本站全部链接为相对路径，天然兼容，无需改动
  - `404.html` 会被 GitHub Pages 自动识别生效
  - `_headers` 是下划线开头文件，GitHub Pages 会忽略（安全头失效，可接受）；若在意安全头，选 Cloudflare Pages
  - 仓库含 28MB 图片——远低于 GitHub 限制，无需 Git LFS
- **开源合规**：分层许可已备好（代码 MIT / 原创文字 CC BY-NC-SA 4.0 / 图片按各自原许可+署名保留）——推 GitHub 前无需再做任何清理；仓库内无密钥、无个人信息
- **首次部署后**：按下方「二」把 sitemap 与 og:image 改为绝对 URL

## 一、部署（三选一）

### Cloudflare Pages（推荐，免费、免备案、自带 CDN 与 HTTPS）
1. 登录 dash.cloudflare.com → Workers & Pages → Create → Pages
2. 选 **Upload assets**，把 `jinsheng-lishui/` 整个文件夹拖入
3. Deploy。得到 `xxx.pages.dev` 预览域名，即已上线
4. `_headers` 文件会被自动应用（安全头 + 缓存策略已配置）

### GitHub Pages
1. 新建仓库，把 `jinsheng-lishui/` 内容推上去（Settings → Pages → Deploy from branch）
2. 注意：GitHub Pages **不支持 `_headers`**，安全头可忽略（纯静态站风险低）

### 传统虚拟主机 / 对象存储
- 整个文件夹上传即可；确保 MIME：`.html` text/html、`.svg` image/svg+xml、`.webp/.jpg` image/*

## 二、绑定自有域名后必须改的两处

| 文件 | 改什么 |
|---|---|
| `sitemap.xml` | 15 个 `<loc>/xxx.html</loc>` 改为 `<loc>https://你的域名/xxx.html</loc>`（sitemap 规范要求绝对 URL，相对路径无效） |
| 各页 `<meta property="og:image" …>` | `assets/img/…` 改为 `https://你的域名/assets/img/…`（社交分享卡片需要绝对地址；16 页页头各一处，全局替换 `content="assets/img/` → `content="https://你的域名/assets/img/` 即可） |

改完重新部署一次。

## 三、收录与观测（可选）

1. Google Search Console / Bing Webmaster 提交 `https://你的域名/sitemap.xml`
2. `robots.txt` 已放行全站（404 页已标 noindex）
3. 若需访问统计，推荐插入 Cloudflare Web Analytics（无 Cookie、不侵犯访客隐私）——不要加重量级统计脚本，与本站的轻量原则一致
