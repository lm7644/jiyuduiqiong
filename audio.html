为什么没有民族语的声音
我们找过了 2026-10 调研
以 Wikimedia Commons API 按「Naxi / Lisu / Bai / Nuosu / Mosuo + 音频」与相应语言分类系统检索：五族语言分类下的音频文件均为零；Lingua Libre（维基媒体录音工程）无纳西语、傈僳语、白语、彝语、普米语条目；检索到的疑似条目逐一核验，均为他语种假命中（如 Tyap 语单词「bai」）。Internet Archive 的民族音乐档案在本次工作网络中不可达，未能核验。
空缺本身是内容 诚实呈现
真实民族语录音存在两大门槛：一是权限——东巴诵经等仪式音声的采集与传播需社区与传承人授权；二是——现存录音多藏于高校、研究院与付费民族语言学档案（如 ELAR、PARADISEC），无开放许可版本。本站不做「用机器合成冒充民族语」的事，因此导览读的是普通话释义，并把田野录音列为与东巴文化研究院、丽江市博物院等机构合作的正式方向（见方法论）。
想听真正的声音 三条路径
① 丽江实地：东巴文化传承展演（丽江东巴文化博物院/玉水寨）与各族自治县节庆；② 权威在线资源见资源目录的纪录片与机构条目；③ 学术档案：论文数据库中检索 Naxi / Lisu songs 的田野录音附册（多需机构订阅）。
